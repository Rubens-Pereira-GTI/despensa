Este projeto utiliza variáveis de ambiente para a configuração do PostgreSQL no Docker.

Para executar o projeto localmente com o Docker Compose, siga estes passos:

1. Crie um arquivo chamado `.env` na raiz do projeto (no mesmo nível deste arquivo e do `docker-compose.yml`).
2. Copie o seguinte conteúdo para dentro do seu arquivo `.env` e ajuste os valores conforme necessário:

POSTGRES_DB=despensa_db
POSTGRES_USER=postgres
POSTGRES_PASSWORD=password
POSTGRES_PORT=5432

Nota: O arquivo `.env` já foi adicionado ao `.gitignore` para garantir que informações sensíveis (como senhas do banco) não sejam enviadas para o controle de versão do git.

Após configurar o arquivo `.env`, você pode subir o banco de dados rodando:
docker-compose up -d
